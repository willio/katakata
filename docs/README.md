# Katakata Documentation

This folder holds the project's canonical documentation, per the Master
Specification's "Documentation" section:

| Document | Purpose |
|---|---|
| [`MASTER_SPECIFICATION.md`](./MASTER_SPECIFICATION.md) | The canonical product specification. Vision, philosophy, architecture, and non-negotiable rules. Everything else derives from it. |
| [`ROADMAP.md`](./ROADMAP.md) | The phased build plan (Phase 0 → Phase 5). |
| [`adr/`](./adr) | Architecture Decision Records — the **why** behind significant decisions. |
| [`subsystems/`](./subsystems) | Subsystem specifications — the **how** behind each part of the system. Populated as later phases land. |

If a decision or behavior isn't explained by the Master Specification, an
ADR, or a subsystem doc, it doesn't belong in the codebase yet.
